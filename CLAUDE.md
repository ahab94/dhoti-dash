# Dhoti Dash: notes for Claude

A satirical desi combat-cycling game in Godot 4.7 (GDScript), in the style of 90s pseudo-3D racers. Chacha Jee, an old man in a dhoti, races rivals on his errands. README.md holds the design and roadmap.

## Run and check
- Play: `godot --path .` (or open in the editor and press F5).
- Every change: `bash checks/verify.sh` must end with `dhoti-dash: all good` (~45s).
  - smoke_test.gd starts and renders every race, and fails on "triangulation failed" errors.
  - game_test.gd checks the data and each mechanic on race.gd directly.
  - checks/autoplay.sh: the expert autopilot must finish every race in the top three.
- Difficulty curve: `godot --headless --path . --script res://tests/sim.gd -- --rookie`. It averages 5 rookies per race and prints lag behind the winner, plus what hurt them. Lag must rise race by race; retune hazard counts and difficulty when it doesn't.
- Use `checks/run.sh SECONDS <godot args>` to run Godot with a wall-clock limit. A script error makes headless Godot hang forever.
- Dev flags go after `--`:
  - `--level=N` (0-based) skips the menu, and `--skip=SEG` starts the field SEG segments down the road.
  - `--autopilot` is the expert bot; `--rookie` is the sloppy one.
  - `--exit-on-end` prints `RESULT level=… finished|retired|timeout pos=… time=… pain=… ko=…` and quits; add `--log-events` for timed EVENT lines (crash_into, aunty_caught, knockout…).
  - `--trace` prints the player's state every half second.
  - `--screenshot=path.png --wait=S` takes one shot. `--wait=1,2.5,4` takes numbered shots.
  - `--touch` shows the touch buttons and lets the mouse press them.
  - `--timeout=S`. Put `--fixed-fps 60` (a Godot flag, before `--`) to run faster than real time.

## Layout
- `scripts/races.gd`: errands as data (road sections, scattered and placed hazards, rivals, billboards). The format is documented at the top.
- `scripts/track.gd`: road segments (curve, height), and scenery props per segment.
- `scripts/hazard.gd`: KINDS (size, depth, effect) and deterministic motion `x_at(t)`, `z_at(t)`.
- `scripts/rider.gd`: rider data, the rival ROSTER (looks, weapon, speed, aggression, skill, taunts) and WEAPONS (dmg, reach, cd).
- `scripts/race.gd`: all the rules. Riding physics, breath, hits, swings, bell, the aunty, rubber-banding, finish and position, and `plan_lane()` (the shared lane planner).
- `scripts/autopilot.gd`: the expert and rookie bots.
- `scripts/renderer.gd`: the pseudo-3D projection, sky, road, sprite buckets drawn far to near, and speech bubbles.
- `scripts/sprites.gd`: every drawing, in world units with y up.
- `scripts/hud.gd`: meters, the progress strip, the aunty mirror, countdown, results, menu and touch buttons.
- `scripts/sound.gd`: music and an SFX pool. It maps race event names to sounds (`EVENT_SOUNDS`). game.gd plays every new `race.events` entry. `audio/` is generated by `python3 tools/make_audio.py` (stdlib only), so don't hand-edit the WAVs.
- `scripts/game.gd`: state, input, flags, saves (`user://progress.cfg`), and the menu's attract-mode demo race.

## Release and videos
- Repo: github.com/ahab94/dhoti-dash (public). Pushing a `v*` tag runs `.github/workflows/release.yml`, which runs the checks, exports Windows/macOS/Linux/Web, attaches zips to a GitHub Release (notes from `docs/releases/<tag>.md`) and deploys the web build to Pages.
- Videos: `bash tools/video/record_footage.sh` (portrait/landscape footage + .events), then `python3 tools/video/make_video_audio.py`, then `/usr/bin/python3 tools/video/make_videos.py`. The video list lives in `tools/video/videos.py`, cut around named events, so re-recording keeps the cuts.
- Phones: touch mode auto-pedals (hold REST to coast). The layout switches to a 720x1280 base when the window is portrait (`game._fit_layout`).

## Conventions
- GDScript: values read from untyped objects need explicit types (`var x: float = r.speed`), not `:=`.
- World text must use `Sprites.text()` or `text_size()`, which snap to TEXT_SIZES. Never pass a continuously scaled font size to draw_string: Godot caches glyphs per size, so it leaked about 2 GB and crashed iPhone browsers (v0.1.1). `--mem` prints memory every 2 s to check.
- Sprites draw with `poly()`/`ellipse()`, which skip tiny shapes. Godot errors on degenerate polygons.
- Movement: riders have sideways momentum (`vx`, eased by LAT_ACCEL). Hits and bumps add to `vx` instead of moving `x` directly. Acceleration fades near top speed. `_steer_towards` aims for a sideways speed proportional to the distance left, so riders settle without overshooting. The camera trails Chacha sideways (`renderer._cam_x`).
- Voices are real recordings: `voices_in/` -> `bash tools/import_voices.sh` -> `audio/voice_rec/<line>.wav`. sound.gd loads the lines that exist (VOICE_LINES, VOICE_EVENTS) and layers CARTOON effects on events. Synthesized speech was tried and rejected by the user ("no emotion").
- game.gd `_juice()`: a 3-frame hit-stop. Slow motion only with `--slowmo` (for recordings; in play it felt like a penalty). `--no-slowmo` disables both; autoplay.sh uses it so results stay deterministic.
- Dogs are "live" hazards that race.gd moves (`_step_dogs`, `_chase`). Every other hazard follows its formula. A dog chases the nearest rider, rivals too, and gives up when outrun (DOG_TOP < Chacha's flat-out speed), startled by the bell, or shooed by any swing. DOG_TURN < STEER so weaving dodges bites.
- Pack pacing (`race._pack_pace`): only riders ahead of the camera are visible, so rivals behind Chacha sprint (harder the further back they are), rivals within PACK_AHEAD match his speed with a small drift, rivals further ahead ease off, and past FINAL_STRETCH everyone rides at 93% of their own top speed. Keep sim.gd's "near" above about 50%, and make sure the expert can still win.
- Combat: anyone hits anyone (`_land_hit`). At pain 100 a rider is `out` (`_knock_out`); Chacha takes the KO'd rider's weapon; `last_standing` ends the race. Everything stays desi: weapons, sounds, words ("DHISHOOM!").
- Sprites: `Sprites.tilt` rotates everything drawn through `P()` (pedal rock, lean, hit wobble). Reset it to 0 after a rider.
- Record clips: `godot --path . --write-movie build/video/x.avi --fixed-fps 60 -- --level=N --autopilot --exit-on-end --timeout=S` (Movie Maker records sound too), then use ffmpeg with `-c:a aac -af loudnorm=I=-14`.
- Satire stays affectionate and non-controversial: no politics, religion, real names or brands (no real bicycle brand), and Chacha is never the butt of the joke. Rivals are named by trade.
- Scripts reference each other with `preload`. Everything is drawn in code. Comments explain why. The user is learning Godot, so briefly explain new engine concepts.
