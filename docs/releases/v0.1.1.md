# Dhoti Dash v0.1.1

A fix for phone browsers.

**Play in your browser (phones too):** https://ahab94.github.io/dhoti-dash/

## Fixed
- **The game no longer crashes phone browsers a few seconds into a race.** Roadside billboards, shop signs and the "DHISHOOM!" bursts drew their text at a smoothly changing size. Godot keeps a separate set of letter images for every font size, so each frame added a new set: memory climbed from about 50 MB to almost 2 GB in under half a minute. Desktops have the memory to hide this, but iPhones close the tab. Text now snaps to a short list of sizes, and a full race stays at about 50 MB.

## Install
- **Browser:** the link above. If your phone shows the old version, reload the page.
- **macOS / Linux:** `curl -fsSL https://raw.githubusercontent.com/ahab94/dhoti-dash/main/install.sh | bash`
- **Windows (PowerShell):** `irm https://raw.githubusercontent.com/ahab94/dhoti-dash/main/install.ps1 | iex`
