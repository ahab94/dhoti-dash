# Dhoti Dash v0.1.2

Sound on iPhones.

**Play in your browser (phones too):** https://ahab94.github.io/dhoti-dash/

## Fixed
- **Sound now plays in iPhone browsers, even with the silent switch on.** iOS mutes web game audio when the ring/silent switch is set to silent, and only allows sound after a tap. On your first tap the page now:
  - asks iOS to treat the game's sound as media playback;
  - on older iPhones, plays a tiny silent clip, which does the same job;
  - wakes up any paused audio.

## Install
- **Browser:** the link above. If your phone shows the old version, reload the page.
- **macOS / Linux:** `curl -fsSL https://raw.githubusercontent.com/ahab94/dhoti-dash/main/install.sh | bash`
- **Windows (PowerShell):** `irm https://raw.githubusercontent.com/ahab94/dhoti-dash/main/install.ps1 | iex`
