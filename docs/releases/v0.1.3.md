# Dhoti Dash v0.1.3

Another go at sound on iPhones.

**Play in your browser (phones too):** https://ahab94.github.io/dhoti-dash/

## Changed
- **Web audio now uses Godot's Stream mode.** The game mixes all its sound itself and plays it as one stream, instead of handing each sound to the browser as a separate sample (Godot 4's default since 4.3). Developers have reported audio problems with sample playback on mobile browsers. Stream mode adds a little audio delay but is the more reliable route.
- **Audio test panel.** Open https://ahab94.github.io/dhoti-dash/?debug=audio to see:
  - the browser's audio state, live;
  - a **TEST BEEP** button that plays a tone outside the game.

  If the game is silent but the beep plays, the problem is in the game. If the beep is silent too, it's the phone or browser settings.

## Install
- **Browser:** the link above. If your phone shows the old version, reload the page.
- **macOS / Linux:** `curl -fsSL https://raw.githubusercontent.com/ahab94/dhoti-dash/main/install.sh | bash`
- **Windows (PowerShell):** `irm https://raw.githubusercontent.com/ahab94/dhoti-dash/main/install.ps1 | iex`
